# Prank Hacker Website

A fun, lighthearted prank website — a fake "hacker terminal" experience you can pull on friends for laughs. Harmless by design: no real hacking, no real tech wizardry, just a convincing-looking prank screen that leaves everyone grinning.

## Features

- **Fake hacker terminal UI** — a dramatic, terminal-style interface that looks like a real "hacking" sequence
- **Single-file app** — everything lives in one HTML file: no build step, no dependencies, works offline
- **Zero setup** — open in any browser and the prank is ready to go
- **Safe & harmless** — purely visual, no network calls, no data collection, no malware

## Tech Stack

- HTML5 / CSS3 / JavaScript (vanilla, single file)
- No frameworks, no build tools, no dependencies

## Quick Start

1. Clone or download this repository
2. Open `index.html` in any modern browser
3. Run the prank on a willing friend 😄
